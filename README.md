
# Kitchen Display System (KDS)

A web-based Kitchen Display System designed to streamline restaurant operations through a digital interface for managing kitchen orders and monitoring their preparation progress.

Built using **React 19, React Router v7, and Firebase v12**.

**[Kitchen Dashboard](https://kds-demo-2c34c.web.app/kitchen)** | **[Phone Interface](https://kds-demo-2c34c.web.app/phone)**

---

## Project Overview

The Kitchen Display System (KDS) is a web application developed to improve the efficiency and organization of restaurant kitchen operations.

Traditional kitchen workflows often rely on printed order tickets and verbal communication, which can lead to misplaced orders, communication errors, and delays during busy service periods.

This project explores a digital approach to kitchen order management by providing interfaces for interacting with the ordering process and monitoring kitchen activities.

The application includes two web-accessible interfaces:

- **Kitchen Dashboard:** Designed for kitchen staff to view and manage incoming orders.
- **Phone Interface:** Provides a separate interface for interacting with the ordering system.

The project demonstrates the use of modern web technologies to build an interactive application around real-world operational requirements.

## System Architecture

The application follows a component-based frontend architecture using React.

### Frontend

**React 19**
- Provides the component-based user interface.
- Manages interactive application states.
- Supports reusable interface components.

**React Router v7**
- Handles client-side navigation.
- Supports application routing and view transitions.

**HTML / CSS**
- Provides application structure and visual styling.
- Supports the layout of the kitchen and phone interfaces.

### Firebase

**Firebase v12**
- Provides libraries for authentication and database-related functionality.
- Supports integration with Firebase services.

### State Management

React state management is used to control application behaviour, manage component states, and reflect user interactions within the interface.
